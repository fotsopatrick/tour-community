5. **Authentification des tests (BLOQUEUR RÉSOLU)**
   - Cause racine : le module `tour_cookie_secure` force le flag `Secure` sur le
     cookie `session_id`. En HTTP local (pas de HTTPS), `requests` ne renvoie donc
     jamais ce cookie → « Odoo Session Expired » partout.
   - Solution : authentification JSON-RPC (`/web/session/authenticate`) puis
     portage MANUEL du cookie `session_id` en en-tête `Cookie`, car
     `s.cookies.set()` ne suffit pas (le flag Secure persiste).
   - Second piège : la route `/community/chat/message` exige un **CSRF token** lié
     à la session (le session id *tourne* à l'authentification). Le token est lu
     sur `/web` (`var odoo = { csrf_token: "..." }`) APRÈS authentification, puis
     passé dans `params.csrf_token`.

6. **Secrets** : grep sur le code de la Tour → aucun secret en clair (vert).
   ⚠️ En revanche, `~/.config/opencode/opencode.jsonc` contient des clés en clair
